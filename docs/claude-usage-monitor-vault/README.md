# claude-usage-monitor

Tooling local pra acompanhar e economizar consumo de tokens no Claude Code: um medidor de consumo no statusline e um painel de uso (sessão/semana) ao vivo. 100% local, lê os logs via ccusage — não gasta token.

- **[[01-Statusline]]** — o medidor de consumo e a linha de uso na barra do Claude Code

- **[[03-Operations]]** — instalar, restaurar após formatar a máquina, GitHub
